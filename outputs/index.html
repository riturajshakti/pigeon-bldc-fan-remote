Before you install

  • Your phone needs an IR blaster. Most phones do not have one — if yours lacks the hardware, the app cannot work.
  • Android will warn about installing outside the Play Store. Allow it for your browser or file manager when prompted.
  • The app only transmits infrared. No internet access, no accounts, no data leaves your phone.

Will it control my fan?

The codes are specific to one fan — a Pigeon BLDC ceiling fan, found by sweeping the command space and testing each response:

ProtocolNEC
Carrier38 kHz
Address0
Commands129–150

A different fan almost certainly uses different codes. The source repository includes the sweep tool used to find these, so you can repeat the process for your own fan.

What it does

  • Power, Light, Timer, Reverse, Sleep, Boost, and speed up/down
  • Direct speed selection 1–5 — the original remote only has + and −
  • A home screen widget with the same dial, no app launch needed
  • Light and dark themes
